## 8. Rollback and Disaster Recovery Instructions

If v1.1 modifications introduce build errors or staging environment bugs:
1.  **Dependency Restore**:
    *   Discard workspace package modifications: `git checkout -- package.json apps/web/package.json`
    *   Restore original lockfile: `powershell -Command "Copy-Item package-lock.json.bak package-lock.json -Force"`
    *   Re-install packages: `npm.cmd install`
2.  **Tooling Removal**:
    *   Delete scripts: `scripts/ci_verify.ps1` and `scripts/build_docker.ps1`.
3.  **Environment Restore**:
    *   Discard `.env.*` files changes.
4.  **Validate Rollback**:
    *   Run `npm.cmd run verify:static` to verify pilot-frozen staging returns to normal.
